# Jester Engine

Jester Engine is a platform for designing, building, and running applications with visual Blueprints and reusable SDK components. The desktop editor brings together project architecture, build configuration, and deployment planning.

This is the public distribution repository. It contains product documentation and release information. The application source code is proprietary.

## Download an evaluation build

1. Open [GitHub Releases](https://github.com/JesterEngine/Jester-Engine/releases).
2. Read the release notes for your operating system, CPU architecture, prerequisites, and known limitations.
3. Under **Assets**, download the installer for your platform. Compare its SHA-256 hash with the checksum published for that release, when available.

GitHub automatically generates archives labelled **Source code**. In this repository those archives contain the documentation at the release tag. Installers are attached separately under **Assets**.
